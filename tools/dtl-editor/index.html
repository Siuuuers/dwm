    A small guide

    1. Import one UTF-8 .dtl file.
    2. Click a caption in the text. Quick controls keep its self-talk pair together.
    3. Insert a label or cue. Edit or remove any line directly.
    4. Review the text and feedback, then export.
    Use existing catalogue IDs for images and audio. Export downloads a file; it does not publish to GitHub.
