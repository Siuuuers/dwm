## Authority and disposition

The lifecycle remains `UNSELECTED → AUDITIONING → SELECTED FOR APPROVAL → APPROVED`, with `REOPENED` when applicable. A direction can be approved at its stated scope while the exact scene is still an audition. A reaction test is not history. Ordinary production promotion retains its scoped selection/approval gate; the legacy [Matrix](../07-seven-day-causal-matrix.md) cannot impose a superseded calendar. Room 2.17's approved-but-unplaced core remains a bounded exception, not a selected new location or encounter.

Whole-week review must test actual occurrence, absence, knowledge, agency, mechanics and surviving consequences before complete DTL. A hidden motive need not be explained to the audience; a deliberately unresolved cause need not be solved for the author. Separate actual carry from speculative history.
