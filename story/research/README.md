# Narrative research

These are the retained literary and physical-plausibility research packets used while developing the story. Start with the [current story home](../README.md) and [Priscilla foundation](../09-priscilla-foundation-amendment.md) to identify the scene and decision that need evidence.

Research supports a question; it does not select a scene or turn an example into a fact of the fictional world. Keep verified external facts, project inferences, fictional policies and unselected staging distinct. A recorded bounded author approval keeps that scope. Relocation on 2026-10-20 did not recheck the external sources or make an old date, timetable, institutional rule or runtime description current.
