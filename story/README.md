## The directory is not a canon stamp

`story/` can contain authoritative documents and clearly marked noncanonical work. The established lifecycle remains `UNSELECTED → AUDITIONING → SELECTED FOR APPROVAL → APPROVED`, with `REOPENED` where applicable. Audition verdicts and reaction tests remain different from canon states.

Retained designs are not final DTL, implementation, or approved placement. Ordinary promotion still needs the established explicit approval and Matrix process; Room 2.17's bounded approved-but-unplaced core is not expanded by this index. See the [existing audition authority contract](../docs/story-auditions/README.md).

## What stays where it is for now

The Bible, Handbook, Matrix, Beatbook, Style Manual, production/public documents, `story/library/`, and technical design sources remain unchanged. Existing `docs/story-auditions/` files still own their recorded content and approval labels. The future layout is specified in the migration manifest, but its file moves have not been performed.

No `story/sources/` folder is created. Raw sources are intended to leave the active tree only after verified Git retention and full substantive coverage. The manifest's pending flags prevent this first-stage foundation from pretending that source retirement has already become safe.
