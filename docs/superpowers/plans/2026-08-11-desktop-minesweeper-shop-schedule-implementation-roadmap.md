## Frozen Cross-Plan Interfaces

### Schedule registry

Plan 01 creates `scripts/domain/schedule/ScheduleActionRegistry.gd`, which loads only `data/manifests/schedule_actions.v1.json`, with exactly:

```gdscript
static func load_current() -> Dictionary
func fingerprint() -> Dictionary
func snapshot(expected_fingerprint: String) -> Dictionary
func lookup(action_id: String, expected_fingerprint: String) -> Dictionary
```

`load_current().value` is exactly `{registry,registry_fingerprint}`; `fingerprint().value` is exactly `{registry_fingerprint}`; `snapshot().value` is exactly `{manifest,registry_fingerprint}`; and `lookup().value` is exactly `{record}`. func publish(publication: Dictionary) -> Dictionary

`prepare_commit()` accepts exactly:
