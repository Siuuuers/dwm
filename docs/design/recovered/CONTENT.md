# 12. Minesweeper placeholder board sizes (real logic = Phase 6)
Beginner 8×8 (10 mines), Intermediate 16×16 (40 mines), Expert 22×22 (99 mines). Cell
size consistent; oversized boards go inside a `ScrollContainer`. Full board logic is
implemented in Phase 6; phases 0–5 use the simulated-result placeholder only.

Mine-density scaling (Phase 6 full-logic): when a real board is generated,
`extra_mines = floor(pressure / 3) + penalty_points_today` mines are added on top of the
difficulty base. This combines Angela's current `pressure` (0..12) and `penalty_points_today`
(0..6) so a more stressed / dangerous state yields a denser field. Clamp so mines never
fill the board (leave the guaranteed first-click safe region). Implemented in Phase 6, not
in the placeholder phases.

INVARIANT: `click_count` MAY fall below 3BV because chording clears multiple cells per
click, so the foresight rate `float(three_bv)/float(max(1,click_count))*100.0` MAY exceed
100%. Phase 6 MUST clamp the displayed rate to a sane maximum (e.g. 999%) and keep the raw
ratio for stats.
