# Desktop Quick commands

F5 and F9 now consume the saved keyboard/controller bindings in the live desktop
launcher and Backup context. Backup's real owner prepares and commits every
operation. F5 targets Quick, preserves the selected drawer and mode, and publishes
Saved only after the synchronous durable write succeeds. F9 always opens the
shared replacement confirmation, including combined fallback consent where
required. Cancel consumes the prepared token; changed source, target, guard or
input custody prevents stale consent from committing.

The launcher has command presentation but the existing production capture owner
still admits saving only from Backup. Other desktop apps and narrative contexts
remain inactive until their capture and protected status placement are connected.
No legacy quick wrapper, queued retry, or fabricated Saving frame is introduced.

## Input and status behavior

Quick actions use physical contacts and the existing InputManager ownership rules.
Rebinding, pause/resume, held contacts, higher focus custody and existing dialogs
retain precedence. A prepared operation rechecks admission after calling its owner.
Successful restore owns the replacement tree; outgoing Quick code does not move
its focus. Cancel restores the surviving control or its rebuilt semantic target.

One inert shell label supplies Saved, Unavailable or Please wait. Saved lasts two
eligible foreground seconds; refusal lasts at most four. Identical current facts
do not reset the timer or repeat the announcement. Suppressed time does not count,
and owner evidence is checked before deferred publication. Contacts notifications
suppress the edge. Backup places it in the blank area above the information pane;
the launcher uses its lower edge. There is no local Backup status twin, icon,
card, sound or focus target.

English, Simplified Chinese and Hong Kong Traditional Chinese use the existing
licensed fonts at 24/30/36 logical sizes. Native rendering covers all 36 language,
size and status combinations; this does not establish OS screen-reader behavior.
