The accepted reference is Shared Shell sections 12.1–12.7, with Witnessed Scene's source restoration requirements. Pause has Continue, Backup, Settings, and Return to Title in that order. ## Preserving the source

`ApplicationLifecycleCoordinator` is a small transient owner on this lineage. It compares the retained physical presentation, mounted current scene, router, mutation gate, runtime generation, request identity, and event before acquiring input, dialogue, and audio suspension. It checks the source again after callbacks and awaited operations. Unknown partial acquisition retains the handle and enters Recovery with the tree paused; it never announces foreground readiness. Continue releases in reverse order and does not replay a release whose Active state was already proved. A changed source cannot be resumed by an old handle.

The implemented eligibility is deliberately narrow: one retained ordinary Hospital presentation at a native live Text event, either revealing or idle. Startup, cleanup, non-text events, transactions, foreign runtime activity, and cached/dormant timeline IDs do not qualify. The shipped Hospital timeline has no reading caption. Native tests therefore install an explicitly synthetic, memory-only timeline resource at its catalog-resolved path and restore the original resource cache. They demonstrate the actual public start and ownership seams without claiming authored Hospital content.

The caption keeps its native label, reveal generation, copies, history, focus, and scroll. Cover hides its Canvas and stops source processing. Restore validates a detached view anchor and restores focus and scroll, clamping only where a changed layout requires it. This uses native visibility; it is not a completed screen-reader traversal audit.

Input custody observes key, pointer, touch, and controller release while Pause is active. Resume quarantines held contacts and the closing frame. It does not globally release actions or consume the Pause UI's own input. The surface controller test explicitly installs a temporary semantic Accept mapping and restores it: the script runner's default map is keyboard-only. Production controller mappings still belong to the canonical Controls integration.

Audio freezes active Music/Ambience playback and existing crossfade tweens in place, preserves prior pause bits, and stops transient story SFX/voice. The UI pool stays available. Resume validates the exact retained native playback object; a paused player's `playing` flag is not a reliable identity check. Failed or ambiguous operations compensate when provable and otherwise report indeterminate state. Dialogue similarly proves its original frontier and physical paused state; a retained handle alone cannot advertise Suspended. New narrative starts are refused while that handle remains.
