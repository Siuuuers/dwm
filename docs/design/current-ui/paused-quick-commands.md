# Paused Quick commands

Saved keyboard and semantic controller bindings reach Quick Save and Quick Load
while the production Pause source is retained. Pause rows, idle Backup and
admissible nonmodal Settings reuse current permission, prepared-token and restore
owners.

Settings keeps custody during reset/commit, volume drag, audio/speech preview,
pending preview cleanup, binding capture/opening, import review, trusted
confirmation and visible native option popups. Other mutation, recovery, focus
and source guards remain authoritative. Blocked shortcuts prepare no action and
queue nothing. Popup events observe the shared physical-contact ledger including
final releases; custody changes, rebinding, focus loss and compound contacts
require fresh input.

Quick Save uses PauseBackupPresentationPort's existing permission and prepared
transaction. Admitted reading Save finishes only the current reveal and saves
that exact semantic point. Settings F5 keeps its host, category, scroll, focus
and suspension. Capability queries stay pure; unsupported frontiers gain no
invented persistence. Synchronous durable writes report Saved without an
artificial Saving frame.

Quick Load prepares the bound Quick revision and opens Cancel-first consent in
the existing Pause workfield without finishing the current reveal. Changed
source, record or focus cancels the token instead of substituting another target.
Settings is covered during consent. Cancel consumes the token and restores the
surviving enabled origin, category and scroll; an unavailable origin uses the
Settings rail fallback. Deferred visibility callbacks cannot overwrite that
origin.

Confirmed Load uses existing suspension release, restore and compensation.
Recoverable failure retains the literal source/current palette and restores focus
only to a surviving source. Successful Load owns the new tree, closes old
Pause/Settings, restores saved canonical route/app/reading point and Dark value,
and preserves pending Profile choice. The restored line is complete without
repeated speech. Retiring the old partial native text event releases its own
reveal wait without publishing completion, granting History credit or waking the
fresh destination. Primary Quick, Autosave and player-profile bytes stay unchanged;
the existing issuer/continuation protocol durably records the restore. Successful
Load is not a zero-write operation. No parallel transcript, save store or restore
path is introduced.

Empty Quick reports No Quick Save. Known inspected refusal retains its specific
compatibility/technical explanation. A non-loadable Backup record does not imply
a usable fallback; an admitted fallback retains explicit confirmation. The inert
QuickStatusEdge remains source/condition-bound, uses existing five-locale copy,
expires only while eligible, and neither repeats announcements nor captures
pointer/focus input. It occupies the unused lower-left Pause region and inherits
the current Pause typography and colours.
