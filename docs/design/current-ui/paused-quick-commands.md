# Paused Quick commands

The existing saved keyboard and semantic controller bindings now reach Quick Save
and Quick Load while the production Pause source is retained. Commands are
admitted from the Pause rows and idle Backup host; Settings/capture, Return
confirmation, owner recovery, other confirmations and held input retain custody.

Quick Save uses PauseBackupPresentationPort's existing permission and prepared
transaction. Unsupported narrative/frontier capture reports Unavailable. The
change does not broaden SaveManager capture or invent narrative persistence.
A successful synchronous durable write reports Saved; no artificial Saving frame
is introduced. The shared inert status edge occupies the unused lower-left Pause
region, inherits the current Pause typography/colours and uses existing five-locale
copy. Eligible-time expiry and nonrepeating announcements use QuickStatusEdge.

Quick Load opens Cancel-first replacement consent directly in the existing Pause
workfield. It leaves the selected row, entered host, Backup drawer and mode
unchanged. Cancel consumes its prepared token and restores surviving focus.
Confirmed Load uses the existing suspension release/restore/compensation owner.
A compensated failure retains the source; a successful Load owns the new tree.
Changed source/condition or focus loss cancels pending consent.

Fresh physical input is required after rebinding, Pause transitions, Settings,
focus loss or a compound held contact. Key echoes cannot repeat writes.

Acceptance for dwm-eei.5: this implements its missing paused-context routing,
with regression coverage through native event dispatch and real paused-dating
SaveManager storage. Engine results are recorded separately by the cloud run.
Live launcher/Backup shortcuts already exist. Other live desktop applications
and witnessed/challenge contexts still lack their general Quick dispatch/status
placement; their save permissions remain determined by the current owners.
Full-context coalescing and broad all-input acceptance remain unfinished.
