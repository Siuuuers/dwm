## 2. Product character, interpretive law, scope, and non-goals

Minesweeper is one **Maintained Survey Worksheet**: a pale calculation sheet
seated inside cheap but correctly maintained university equipment. It records
covered cells, negative estimates, clears, explosions, flags, and one marked
mine with the same administrative sincerity. It assigns none of them meaning.

The private governing law is:

> Night contains the instrument; the instrument contains the worksheet; the
> worksheet exposes only the evidence produced by play.

The audience sees exact evidence and decides what it means. The apparatus does
not explain pressure, hidden extras, safety, Perfect, a relationship outcome,
route, or why one post-clear mine matters. Robert McKee, Alain Robbe-Grillet,
Roland Gérard Barthes, and Mark Fisher remain private calibration lenses, never
player-facing attribution or copy.

### 2.1 Current-v1 scope

This dossier closes only:

- the desktop app and canonical solo/pair challenge Minesweeper projections;
- the exact reusable board worksheet, register, dock, grid, scroll, sheet,
  terminal, Focus, input, and accessibility surfaces;

## 3. Vocabulary, ownership, and state partition

### 3.1 Closed current-v1 vocabulary

- A **host** is exactly `desktop_app`, `canonical_solo`, or
  `canonical_pair`. Historical `rehearsal_solo` and `rehearsal_pair` values
  remain source provenance only and publish no current-v1 UI.
- An **unpaid worksheet shell** is the saveable covered pre-materialization
  state that may retain flags, Flag/Unflag receipts, action count, and No-flag
  without owning mines, RNG draw, candidate, cost, or result.
- A **board generation envelope** is one shell, candidate, prepared layout, or
  adopted layout with its ordinal, identity, immutable spec, public actions,
  metrics, terminal fact, and command receipts.
- A **touched layout** has one accepted Reveal. Contact, Focus, navigation,
  panning, mode change, pre-Reveal Flag, or Debug preparation does not touch it.
- A **paid desktop session** begins with one committed paid first Reveal and
  ends with one terminal result or governing forfeit. It may contain multiple
  sequential free replacement envelopes but only one cost receipt and signed
  round ordinal.
- **Action count** is the number of committed Reveal, Flag, Unflag, and Chord
  commands in one envelope. It begins on the shell and freezes at terminal.
- **Foresight** is exact `3BV / action_count`, displayed as the floored integer
  percentage and qualified by exact rational comparison.
- **No-flag** is one envelope Boolean that irreversibly becomes false on the
  first committed Flag and resets only for a genuinely new envelope.
- **Perfect** is a terminal classification whose nonempty sorted reason set is
  drawn only from `efficiency_gte_100` and `no_flag`.
- A **special mine** is one canonical-solo mine identity frozen with the adopted
  layout and indistinguishable until a non-Perfect clear lawfully marks it.
- **Terminal inspection** is the settled, read-only desktop worksheet plus
  frozen public facts and legal next actions. It cannot command cells or settle
  consequences again.
- **Custody** exists only while a real admitted generator, replacement,
  settlement, modal, or recovery owner controls input or transition across
  visible frames. Immediate publication never fabricates it.

## 4. Exact native mounting, bands, wells, grid, sheets, and terminal geometry

### 4.1 Native evidence space and current hosts

Every Standard master is authored at 640×360 native pixels and displayed at

prototype evidence are forbidden.

| Current-v1 context | Global native rectangle | Logical rectangle |

| Desktop Minesweeper body | `(240,32,400,328)` | `(480,64,800,656)` |

### 4.5 Worksheet well and conditional scrollbars

The worksheet reserves one trailing and one bottom gutter equal to the current
cell target:

| Target mode and host | Content well | Trailing gutter | Bottom gutter |
|---|---:|---:|---:|
| ordinary desktop | 376×222 | 24 | 24 |
| ordinary challenge | 456×222 | 24 | 24 |
| Large desktop | 368×200 | 32 | 32 |
| Large challenge | 448×200 | 32 | 32 |

The bottom-right corner is inert. A scrollbar, thumb, hit target, Focus target,
and assistive node exist only on an axis whose exact grid mount overflows. A
fit-axis gutter remains empty habitat with none of them.

Let `W` and `H` be worksheet-band width and height, `T=24` ordinary or `T=32`
Large, `A_w=W-T`, and `A_h=H-T`:

- content well: `(0,0,A_w,A_h)`;
- vertical rail: `(A_w,0,T,A_h)` only when `mount_height>A_h`;
- horizontal rail: `(0,A_h,A_w,T)` only when `mount_width>A_w`; and
- inert corner: `(A_w,A_h,T,T)`.

For either axis, let `L` be rail length, `A` viewport extent, `M` mount extent,
and `s` the integer offset in `[0,M-A]`. Thumb length is
`max(T,floor(L*A/M))`; leading offset is
`floor((L-thumb_length)*s/(M-A))`. Focus correction clamps `s` before deriving
the thumb and never moves the board fractionally.

Dark scrollbars use maintained instrument material, Fog Blue structure, and a
