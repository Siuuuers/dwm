# Shared Title and Desktop Shell Standard Palette and State Disposition

## 1. Accepted decision and objective

The project owner approved the complete recommended shared-shell batch on
2026-08-22. This disposition records that accepted direction for the logged-out
title, in-run desktop shell, persistent Angela panel, audience clock, global
nonblocking surfaces, Pause, confirmations, and technical recovery.

The shell presents a competent institution that records public facts and real
consequences without interpreting them. Its central visual law is:

> Keep the procedure sincere. Change the interface only when its public fact
> changes. Never style an anomaly as an anomaly.

The shell therefore exposes evidence but supplies no decoding key. It adds no
story explanation, route hint, relationship meter, anomaly badge, fake
malfunction, or decorative state. It authorizes no implementation.

## 2. Authority and narrow supersession

The Main Menu, Desktop Shell, and Global Chrome amendment retains ownership of
all geometry, commands, routing, cache, focus, clock behavior, HUD facts,
self-talk behavior, safe regions, persistence, and failure law. The later title-
art amendment retains ownership of the inert optional title-art presenter. The
Ordered Ending amendment retains Pause behavior. Contacts retains toast content
and notification lifetime. Backup retains Quick lifecycle and exact save truth.
The global semantic alphabet and functional-state morphology retain the meaning
and invariant non-colour evidence of every shared state.

This disposition closes only the following current visual decisions:

- provisional After-Hours Standard and Midnight Standard shell mappings;
- shell material relationships and component projections;
- risk and status placement where existing authorities already own the fact;
- separation of desktop self-talk material from witnessed-scene caption
  material; and
- the Standard-master proof fixture family.

It narrowly supersedes earlier statements that the two Standard surface
mappings have no accepted direction. For the six named derivatives only, it
also advances their earlier unapproved-candidate status to provisionally
registered for these Standard-master proofs. It does not accept them for High
Contrast, Protan, Deutan, Tritan, or production use. All derivative values and
Standard role mappings remain provisional until final native-pixel proof; this
disposition does not declare either Standard master production-ready.

It does not settle High Contrast, Protan, Deutan, or Tritan mappings. It does
not change any application topology or manufacture a state merely because a
visual token exists for it.

The retained shell authorities express geometry on a 1280-by-720 logical
canvas. This disposition's native-pixel evidence uses the exact 2:1 proof
mapping to 640-by-360: one native pixel equals two logical pixels in both axes.
Thus native `(160,32,480,328)` is the evidence-space form of logical
`(320,64,960,656)`, and a 32-native-pixel strip is the evidence-space form of a
64-logical-pixel strip. Native notation never supersedes logical geometry.

### 3.2 Shared semantic roles

After-Hours maps habitat to Void and controlled faces to Deep Navy. Midnight
maps habitat to Green-Black Glass and controlled faces to Blackened Verdigris.

Across both masters:

- Bone Text is primary copy on controlled dark;
- Fog Text is secondary copy on controlled dark;
- Fog Blue is structure and nontext registration, never meaningful text proof;
- Worn Cream is reserved for documentary or trusted-sheet material;
- Filed Verdigris is the commitment plane for Selected or Current only;
- Bruised Plum is a low-value inward or diegetic material, not a warning;

  wording, glyph, and rule; and
- authored title art, Angela art, tableau art, keepsakes, app art, portraits,
  and decorative icon pixels remain outside functional recolouring.

### 3.3 Focus and contextual proof

Focus remains the detached double outline and never becomes Selected.

- On After-Hours dark, Bone Text is the outer focus and Tarnished Gold the
  inner focus.
- On Midnight dark, the same semantic roles map to Bone Text and Tarnished
  Gold.
- On Worn Cream, the current theme habitat supplies the outer focus and Deep
  Brass supplies the inner focus.
- On Filed Verdigris, the current theme habitat and controlled dark supply the
  detached rails and gap.

Bone Text and Fog Text cannot prove content directly on Filed Verdigris.
Selected and Current components therefore use contextual dark ink and seam.
Warm Warning, Danger, Error, or Destructive colours cannot prove state directly
on Worn Cream. Their paper projection therefore uses contextual dark copy,
glyph, and governing morphology.

## 4. Logged-out title shell

### 4.1 Lawful palette states

A fresh-profile title without Dark entitlement is lawfully After-Hours only.
It contains exactly these visible ledger rows:

1. New Acc;
2. Log in;
3. Gallery;
4. Settings; and
5. Shut down.

The missing Dark selector has zero geometry, seam, gap, lock, help, focus stop,
or assistive node.

Once entitlement exists, the pending next-run selector may project between New
Acc and Log in. Pending Off uses After-Hours functional material; pending On
uses Midnight functional material immediately. This changes the title's
functional base palette only. It does not recolour optional title art, claim
that a current run is Dark, or explain the entitlement.

New Acc freezes the pending value and publishes the new run only at the
existing durable boundary. A Midnight run therefore appears without an
After-Hours flash. Cancel or failure leaves the title palette, pending intent,
records, and continuation unchanged.

### 4.2 Ledger, workfield, and host strip

The title ledger is a controlled-dark institutional directory. The unhosted
workfield is the current habitat. One Fog Blue structural seam separates the
two regions.

Ledger rows use neutral controlled-dark faces with Bone Text and Fog Text.
New Acc is not visually recommended, Dark is not ominous, and Shut down is not
permanently destructive. Hover, Press, Focus, Selected, risk, and custody appear
only when their corresponding public facts exist.

When Log in, Gallery, or Settings is hosted, its ledger row remains neutral.
The literal host-strip title and visible destination already prove location;
the shell does not invent a second Current or Selected mark. Return remains an
ordinary action and restores the exact source-row focus.

The empty title strip projects only the truthful clock. Return and host title
remain absent. A hosted strip uses the theme's controlled dark, Bone Text for
its title and clock, Fog Blue registration, and one ordinary Return target.

### 4.3 Optional title-art presenter

The unhosted title-art presenter owns the accepted native rectangle
`(160,32,480,328)`. When no optional title art exists, the presenter is not
drawn. There is no frame, copy, aperture outline, placeholder, fallback, error,
focus target, or accessibility node.

When a title destination is hosted, the presenter is completely hidden.
Future optional art remains inert and unaltered and contains no baked clock,
focus, Dark state, save state, or functional instruction.

### 4.4 Title confirmations

New Acc remains a neutral ledger action. If a live continuation or nonempty
Autosave will be replaced, the trusted confirmation owns Warning and Cancel
owns initial Focus. The final `Start` action owns Danger because it knowingly
abandons continuation but is not an explicit Delete or Overwrite command.

Older prose describing this case as a “destructive warning” does not assign the
global Destructive-action token. Shut down remains a neutral trusted
confirmation and never fabricates a Save or deletion.

## 5. In-run computer shell and launcher

### 5.1 Shared chassis and app strip

The computer body and empty app canvas use the current habitat. The 32-native-
pixel app strip and controlled action faces use the current controlled dark.
The strip projects one Home target, one literal current title, and one
noninteractive tabular clock. It adds no Back icon, active-app badge, taskbar,
or second selection indicator.

The visible app and its literal title prove the current app. Cache, restore,
route ownership, and active-app identity remain private state and receive no
Restored, New, Success, recency, or replay mark.

### 5.2 Launcher registry

The launcher projects seven controlled-dark registered cells in the accepted
four-column, two-row geometry. The eighth position is habitat only: it has no
cell, seam, icon, label, focus target, tooltip, accessibility node, or mystery
meaning.

Every real cell owns its fixed 24-by-24-native icon aperture and literal label.
The label is the operational proof. Icon art remains unaltered. Missing icon
art uses the stable generic silhouette without changing route, label,
ownership, or focus. This disposition creates no remappable-icon class, asset
manifest capability, or alternate icon pipeline.

Focus, Hover, and Press occupy their independent zones and never open an app.
Only explicit activation invokes the command. Log out remains an ordinary
launcher action until its trusted consent surface exists.

### 5.3 Home and return truth

On the launcher, Home alone is Current, Disabled, and nonfocusable. It uses the
Filed Verdigris commitment plane with contextual dark ink and blocked-action
evidence. Bone Text and Fog Text do not sit directly on Filed Verdigris.

When an app is open, Home is an ordinary enabled action. Under a higher custody
owner it becomes temporarily inert through that owner rather than acquiring a
new canonical Disabled identity. No activation queues behind the owner.

Returning Home restores focus to the actual source app icon. Reopening an app
restores only still-valid app-local focus, scroll, and selection under that
app's law. It creates no visible cache or restoration status and replays no
command or announcement.

## 6. Angela panel

### 6.1 HUD register

The HUD is one continuous opaque controlled-dark typographic register with Bone
Text tabular values, Fog Text labels, and Fog Blue structural rules. It projects
only the already-authorized Day, audience Pressure, Health, Motivation, exact
money, exact coins, and exact present condition or penalty.

It contains no meters, progress bars, traffic colours, threshold zones,
warning inference, score treatment, or hidden-range evidence. A number is
neutral content. A condition or penalty is also neutral content unless a
separate owning authority explicitly classifies that exact public fact as a
risk. Absent condition and zero penalty remain negative space.

### 6.2 Tableau and keepsakes

Angela, the room/tableau, backgrounds, and keepsakes remain authored art and
are never functional palette targets. Keepsake sockets have no state frame,
friend identity, provenance, route, evidence, relationship, or anomaly mark.
An owned keepsake whose final art is missing uses its accepted stable inert
silhouette in the same socket. Missing Angela or tableau art uses the accepted
safe noninteractive fallback. Neither case may omit a truthful ownership or
functional fact.

The HUD and self-talk remain functional if Angela or tableau art cannot be
shown safely. Missing required HUD copy or an unresolved semantic projection is
technical failure and enters trusted recovery; it is never presented as an
artistic blank or story anomaly.

### 6.3 Desktop self-talk material

Desktop self-talk receives its own low-value Bruised Plum dock with controlled-
dark leaves and Fog Blue registration. Bone Text and Fog Text retain their
ordinary meaningful-copy roles. It is not Worn Cream paper.

This is a shell-specific self-talk material decision. It retains the accepted
caption behavior but does not inherit the witnessed-scene Room-Owned Aperture
Registered Material Field. “Current beat” denotes bottom-up chronology only;
it is not the global Current state and receives no Filed commitment plane.

Ordinary cues and the pinned Dark Schedule refusal use the same material. The
refusal gains no Warning, Error, status-banner, or technical-failure skin. Its
literal content, protected lifetime, and the rejected command are the complete
public evidence.

## 7. Audience clock

The title and in-run clocks share one ordinary component mapping: Bone Text
tabular `HH:MM` on controlled dark, with no seconds and no focus target.

The rare in-run wrong-time allocation uses exactly the same visible and
assistive typography, colour, edge, spacing, label grammar, and component
identity as routine time. Only the frozen displayed value differs. It receives
no anomaly hue, glyph, border, tooltip, live announcement, sound, glitch,
status, or later explanation. The title clock never consumes the anomaly.

If the system clock cannot be read, the clock capability projects the accepted
unavailable value such as `--:--` and a truthful localized semantic label. It
uses the Unavailable morphology appropriate to that exact clock capability,
not Disabled-action styling, and never preserves stale time as current.

## 8. Global surfaces and custody

### 8.1 Contacts toast

The Contacts toast is a quiet controlled-dark Information plate with Fog Blue
registration, Bone Text primary copy, and Fog Text secondary copy. Its closed
content remains `New message`, the literal friend name, `Go`, and `X` only.

It has no portrait, preview, timestamp, count, invitation category, timer bar,
Unread gutter, route hint, sound, motion, or initial Focus. Dismissal and timeout
do not clear the Contacts-owned message-Unread fact. The toast queues whenever
no lawful safe region exists.

### 8.2 Quick status

Quick status is a separate noninteractive edge surface. Exact `Saving…` owns
Busy only while a real accepted Quick request remains pending across visible
frames. Exact `Saved` owns the existing two-second foreground Success lifetime
only after durability is proven. The typographic ellipsis is the normative
source form; older ASCII `Saving...` prose is placement shorthand.

An immediate Quick operation skips Busy. Busy and Success never coexist for
the same operation. The surface adds no icon, spinner, percentage, progress
animation, sound, focus target, or universal save status. Contacts toast wins a
safe-region collision; Quick queues or relocates without covering protected
content.

### 8.3 Immediate and visible-duration commands

An immediate shell command publishes its accepted result or destination
directly. It receives no Busy or Success interstitial. A genuine multi-frame
route or transaction may own silent static custody only while that operation
is actually in progress; the shell invents no pending copy or minimum dwell.

Backup's exact operation surfaces and Quick's exact edge status remain narrow
exceptions. Their wording and lifetime do not become a universal shell
pattern.

### 8.4 Blocking confirmation and recovery

A trusted confirmation uses one Worn Cream sheet within its accepted safe
rect. Contextual dark text, glyph, and rule carry the state. Gold, Fired Rust,
or Fired Rose Enamel never serve as the only paper evidence.

Technical recovery may replace the full canvas with an opaque current habitat
and one Worn Cream factual recovery sheet. It is cleaner and more neutral than
ordinary chrome. It contains no translucent recolouring of art, fake code,
horror distortion, character attribution, raw identifier, or anomaly meaning.
The last trustworthy state remains beneath or is reconstructed where safe.

### 8.5 Pause

Pause is an orthogonal presentation and input-custody mode, not Busy, Warning,
Disabled, or an anomaly. Continue owns initial Focus. The accepted preview row
may own Selected independently from Focus. Hover never selects.

The frozen source art remains unaltered beneath one static theme-habitat glass
veil: Void-family glass in After-Hours and Green-Black-family glass in
Midnight. The veil is decorative and uses one proof-calibrated constant within
each Standard master; its transparency never carries state. The left 240-native-
pixel action pane uses an opaque controlled-dark backing. Its four rows use the
ordinary dark action grammar. The right context strip uses controlled dark;
when Continue is selected, its title and workfield remain absent so the frozen
source is visible through glass. Backup and Settings bring their own accepted
opaque materials into the right workfield rather than inheriting glass.

Functional copy, controls, status, and Focus always sit on independently
contrast-safe opaque backing. Selected preview uses Filed Verdigris with
contextual dark ink and seam. High Contrast may later make the decorative veil
fully opaque without changing any fact. Pause projects no Home, audience clock,
launcher, notification, or active-app mark.

Return to Title remains an ordinary Pause action until activation. Its trusted
confirmation owns Warning; the final `Return to Title` owns Danger because it
abandons unsaved continuation but does not explicitly delete a Backup record.
Cancel owns initial Focus.

## 10. Standard-master fixture family

The first proof family contains six Standard contact sheets:

> After-Hours and Midnight × 100%, 125%, and 150% text masters

Each sheet contains two target-mode columns. Every fixture state is rendered as
one complete 640-by-360 capture in the 24-by-24 target column and again as one
complete 640-by-360 capture in the 32-by-32 target column. Every capture remains
1:1 native pixels; annotations remain outside the captured canvas. A manifest
record belongs to one capture and therefore names exactly one target mode.

The fixture legality mask must reject impossible combinations. In particular,
a fresh-profile/no-entitlement title is After-Hours only. A Midnight title
requires entitlement and pending Dark On.

The contact sheets collectively prove:

   presenter;

   hidden presenter;

   genuinely absent eighth position;

## 11. Rejection and failure fixtures

A Standard master fails as a unit if any required pairing or collision fails.
Release evidence must reject at minimum:

- a pre-entitlement Dark gap, node, marker, or phantom focus stop;
- an impossible fresh-profile Midnight state;
- the optional-art presenter surviving a hosted destination;
- the title clock acquiring an anomalous value or anomaly treatment;
- Home remaining focusable or actionable on the launcher;
- a marked, focusable, or assistively exposed eighth launcher position;
- multiple visible apps, ghost focus, wrong return icon, or invalid cache replay;
- toast or Quick status covering protected content, stealing focus, or appearing
  above a warning or recovery owner;
- fake `Saving…`, simultaneous pending and settled status, or Success before
  durability;
- a Focus-plus-risk collision in which either invariant morphology becomes
  illegible;
- clipped detached Focus, colour-only evidence, opacity-only unavailability,
  resampling, native-coordinate drift, clipped copy, ellipsis, shrink-to-fit,
  or horizontal text scrolling;
- recoloured art, art-dependent functional contrast, broken-image badges, or
  semantic decoration inside authored art; and
- assistive-only anomaly explanation, hidden-stat leakage, private pictograms,
  or scaffolds for Observer UI, avatar frames, the visual anomaly generator,
  post-v1 apertures, or special-ending visuals.

Missing optional title art is intentional absence, not recovery. Missing
decorative app, keepsake, Angela, or tableau art uses only the accepted inert
fallback while functional shell facts remain intact. Missing required app
projection, localization, or HUD labeling enters trusted recovery. Clock
adapter failure yields unavailable time. Route construction failure retains
the last stable shell and exact focus. Quick failure preserves prior save truth.
