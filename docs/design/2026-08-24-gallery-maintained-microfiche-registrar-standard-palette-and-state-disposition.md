# Gallery Maintained Microfiche Registrar Standard Palette and State Disposition

## 1. Accepted decision and objective

The project owner approved the complete recommended current-v1 Gallery design
batches on 2026-08-24. Gallery becomes one maintained campus microfiche
registrar: a narrow controlled-dark discovered-record index beside a larger
Worn-Cream record desk, with one pinned action dock and no simulated file
browser, card catalogue, or theatrical projector behavior.

The current private covenant is:

> The registrar files only what happened; the unbuilt annex leaves no missing
> door.

This sentence is private design shorthand. It is not visible copy, assistive
copy, a hint, or an audience-facing explanation.

Gallery shows only public evidence already owned by its retained authorities:
personal discovery order, registered authored record copy, optional registered
media, witnessed versions when more than one exists, Replay availability, a
real History merge result, and truthful technical failure. It does not explain
what an ending means, expose a missing identity, assign a speaker, imply a
completion denominator, or interpret the evidence it files. Minesweeper
results remain the sole choice-like narrative agency under their own authority.

This disposition closes only the current Endings presentation layer:

- the exact native registrar mount and split;
- index, record paper, optional media, version register, and dock anatomy;
- Standard material and component mappings;
- Focus, Hover, Press, Selected, Disabled, Information, custody, and failure
  composition;
- focus, pointer, scrolling, Replay handoff, return, and recovery projection;
  and
- the future native-pixel proof family.

It authorizes no Godot implementation, runtime or test mutation, asset
production, localization writing, Rehearsal scaffold, profile consumer, work
item, Beads mutation, branch, implementation plan, or release claim.

The Gallery/Rehearsal Archive UI/UX Amendment remains the sole behavioral owner

The Haunted Instrumentarium foundation, Global Functional Semantic Alphabet,

The Visual-Art guide retains semantic manifests, registered exports, immutable

The Deferred UI Feature Register is authoritative for the complete Rehearsal
deferral.

### 2.2 Current-v1 Endings-only closure

Current-v1 Gallery is Endings only. There is no local Endings heading because
the shell already names Gallery and no current peer register exists.

The complete Rehearsal function is future-only. Current Gallery therefore
contains no:

  Begin Rehearsal action, or sandbox surface;

  migration, or recovery branch; or
- geometric, semantic, architectural, or implementation scaffold.

Nothing in this disposition promotes, partially implements, or weakens that
deferral. The preserved future design remains in the Deferred UI Feature
Register and requires a new explicit owner decision before any promotion.

### 2.3 Exact narrow clarifications

Within current Gallery presentation only, this disposition resolves these
previously open or superseded details:

1. The older conditional two-mode geometry becomes the full-height Endings-only
   body in section 3. No mode-shaped absence remains.
2. The former approximate split becomes one exact native index, habitat gutter,
   record desk, record paper, and dock composition.
3. The record list is a ruled registrar index, not the checked-out button grid,
   a card wall, a completion checklist, or a category browser.
4. Hover uses a leading contact rule and Press uses the reversed upper rule.
   Neither changes a paper fill, selects, focuses, or starts Replay.
5. Selected uses Filed Verdigris plus the accepted filing seam while Focus
   remains detached.
6. Pointer wheel, trackpad, and touch scrolling use the owner beneath the
   pointer; keyboard and controller scrolling use the owner holding focus.
   This narrowly replaces the older focus-only wording for pointer scrolling.
7. Fit-axis scroll witnesses are absent. Overflow witnesses are inert evidence,
   not a third control family.
8. A record change resets its record paper to the top. A version change retains
   the selected version identity and uses the smallest stable correction needed
   to keep that row visible.
9. Immediate Replay admission has no loading state. Genuine cross-frame custody
   uses only the accepted static double seam.
10. A determinate preparation failure uses the exact concise status in section
    11 and revalidates only the same record and version.
11. Current technical recovery is a shared trusted surface; Gallery does not
    invent a microfiche-themed recovery modal.

No other behavior, copy, mechanic, identity, persistence rule, or command is
reopened.

## 3. Exact current-v1 native mounting

### 3.1 Coordinate contract

Geometry is authored on the exact 640-by-360 native master and displayed at
2:1 on the 1280-by-720 logical canvas. One native pixel equals two logical
pixels. All rectangles in this disposition are Gallery-host-local native
coordinates unless stated otherwise.

No Gallery-local title, clock, Return, window frame, close button, mode key,
header-shaped reservation, or floating panel is added.

### 3.2 Scaling and target law

The split, dock, gutter, scroll wells, and reading order remain stable at 100%,
125%, and 150% text. Copy wraps vertically; rows grow and scroll extent changes.
Nothing clips, ellipsizes, horizontally scrolls, silently shrinks, or changes
macro topology.

Every interactive row and action has a minimum 32-native-pixel body, satisfying
the retained 64-logical-pixel archive target. Four-native-pixel detached Focus
clearance is reserved separately from the semantic body. Target and Focus
geometry never create another visible row or semantic node.

Fractional placement, fractional scaling, resampling, animated layout,
container remainder distribution, and horizontal scrolling are forbidden.

## 5. Discovered-record index anatomy

### 5.1 Index regions

| Region | Native rectangle |
|---|---|
| index focus lane | (16,16,156,296) |
| index scroll well | (172,16,8,296) |

The lane and well are adjacent and do not overlap. The first row begins at
native y = 20. Rows are top-packed in personal first-discovery order. Uneven
blank space remains below the final row and communicates no missing record.

Let N_i be record i's wrapped title height. Under the active microtype tuple,
N_i is its line count times L. Then:

- H_i = 8 + max(32, N_i)
- row body = (20, Y_i, 148, H_i)
- title measure = row-local (8,4,132,N_i)
- bottom rule = row-local (8,H_i-1,132,1)
- Y_1 = 20
- Y_(i+1) = Y_i + H_i + 4

The title's first row-local baseline is 4 + B; each subsequent baseline advances
by L. The title uses gallery.type.index_title and gallery.index.primary. It is
top-aligned and never vertically redistributed inside a taller row.

The row contains only its fully wrapped authored title and mandatory bottom
rule. It has no number, count, category, status badge, thumbnail, missing slot,
mechanical subtitle, date, speaker, completion mark, or route clue.

### 5.2 Discovery, selection, and absence

Undiscovered identities have zero geometry, order position, gap, placeholder,
focus stop, assistive node, tooltip, denominator, or decorative proxy.
Rediscovery and Replay never reorder the index.

The selected record owns one full Filed Verdigris plane and one two-pixel filing
seam at row-local (146,0,2,H_i). Its title and mandatory rule remain legible in
contextual dark ink. Detached Focus expands four native pixels beyond its
semantic body and never becomes the Selected seam.

Hover adds only the leading contact rule. Press replaces that response with the
upper contact rule for the physical hold. Neither state changes row geometry,
fill, order, copy, selection, or record publication.

Index overflow is honest: rows retain their full height and title. Gallery
never shrinks rows, creates columns, hides a long title, or reserves space for
unseen identities.

### 5.3 Empty Endings

With no discovered record:

- the index is bare controlled dark;
- the record paper shows exactly one approved factual localized sentence in
  (196,16,260,E), where E is its wrapped line count times L;
- media, title, version heading, version rows, Replay, and both scroll witnesses
  have zero geometry; and
- the dock remains structurally present but empty.

There is no heading, border, icon, progress count, call to action, unlock hint,
or Rehearsal reference. The sentence's first baseline is 16 + B and every later
baseline advances by L. The remaining paper is bare. Focus rests on the shell
Return control. If the approved sentence exceeds the 256-pixel viewport in a
real supported locale, proof fails; Gallery does not clip, shrink, or invent a
second empty-state topology.

## 8. Focus, pointer, and spatial navigation

### 8.1 Fresh entry and current selection

Current-v1 Gallery always opens on Endings.

- If at least one discovered record exists, the first record in personal
  first-discovery order becomes Selected and receives initial semantic Focus.
- If no record exists, Gallery creates no phantom internal focus target and the
  shell Return control receives Focus.
- Opening Gallery never starts Replay.

This current-v1 rule narrowly replaces the older empty-Endings branch that
could focus Rehearsal. Rehearsal is deferred and contributes no current target.

The Gallery view cache survives only the retained direct-Replay round trip.
Leaving Gallery destroys it. A later fresh entry therefore begins under the
rules above rather than pretending the previous inspection was saved.

### 8.2 Record and desk navigation

Record Focus and record Selection are coupled. Moving keyboard or controller
Focus onto a discovered row selects that row and republishes its record paper
immediately. It starts nothing.

Up and Down move through visible records in personal discovery order without
wrapping. At either boundary Focus remains on the current record. Every newly
focused row is brought completely into view with the smallest stable movement
that includes its detached Focus clearance.

Right from the selected record advances through this exact truthful path:

1. Record details, only when the record paper genuinely overflows;
2. the currently selected witnessed-version row, only when at least two
   versions exist; and
3. Replay, only while it is available and focusable.

If no deeper target exists, Focus remains on the selected record. Left from
Record details, a version row, or Replay returns to that selected record without
changing Selection or scroll position.

Tab follows visible order: all discovered records, Record details only on real
overflow, witnessed-version rows only when plural, and Replay only when
available. Shift-Tab reverses it. The shell Return remains in the shell-owned
graph and is not duplicated inside Gallery. Disabled Replay is visible when its
public fact requires it but is skipped by sequential and spatial traversal.

### 8.3 Version navigation

Up and Down within the witnessed-version register move without wrapping.
Selecting a version immediately republishes its registered public projection
and starts nothing. Its stable public identity retains Focus; when the
republication changes content height, Gallery makes only the smallest static
scroll correction needed to keep the focused row completely visible.

No Accept, Enter, Space, click, tap, or double activation on a record row,
Record details, or version row begins playback. Only Replay owns that command.

### 8.4 Pointer law

Pointer intersection creates Hover only on a currently inspectable target.
Hover changes neither Focus nor Selection and republishes no record.

Physical hold creates only Press. Release inside a record or version row moves
semantic Focus to that row and selects it. Release outside cancels the contact
without mutation. The detached Focus paint follows the shared focus-visible
input-modality law; a pointer press never borrows Focus morphology as its
contact response.

Double-click and double-tap on a record or version have exactly the effect of
one selection. The second activation is ignored as an additional command and
never reaches Replay.

### 8.5 Focus repair

Scrolling alone never steals Focus. A profile refresh that removes the focused
record or version uses the retained deterministic archive fallback law. If an
authoritative refresh disables Replay while Replay owns Focus, Focus returns to
the selected record without changing record or version Selection.

Decorative paper, media, rules, habitat gutter, blank index capacity, dock
capacity, scroll witnesses, and absent controls never enter the focus or
assistive graph.

## 9. Scroll ownership and witnesses

### 9.1 Two owners only

Gallery has exactly two possible vertical scroll owners:

- the discovered-record index; and
- the record paper when its content genuinely overflows.

Pointer wheel, trackpad, and touch-drag input applies only to the owner beneath
the pointer. Keyboard keys and controller stick input apply only to the owner
holding Focus. Input at one owner's boundary stops there; it never leaks into,
selects, or moves the other owner.

While Record details owns Focus, Up, Down, Page Up, Page Down, Home, End, stick,
wheel, trackpad, and touch input scroll that paper without changing the selected
record or activating an action.

Scrolling is immediate and static. There is no easing, momentum, bounce,
overscroll, auto-scroll, fade, moving-paper effect, or sound requirement.

### 9.2 Overflow-only witnesses

Let:

- V be the viewport height;
- E be the complete content extent; and
- o be the current offset clamped to 0 through E - V.

- thumb y = floor((V - thumb height) × o / (E - V)).

uses one exact trailing-biased raster:

- index thumb = (175,16+thumb y,3,thumb height);
- record track = (468,16,1,256); and

When E is less than or equal to V, the track, thumb, well semantics, hit target,

The visible track and thumb are position evidence only. They are not focusable,

## 10. Replay admission, custody, Back, and return

### 10.1 One explicit admission point

Replay is the only Gallery command that begins direct Endings playback. One
click, tap, Enter, Space, or controller Accept on Replay revalidates the exact
currently selected semantic record and witnessed version.

Revalidation may change only truthful availability and admission. It never
chooses another record, silently substitutes another version, or begins a
fallback playback.

If revalidation refuses ordinary admission before preparation, no session or
mutation exists. The dock states Unavailable and Replay uses its Disabled
open-bottom gate. The discovered record itself remains ordinary, selected, and
inspectable; the refusal does not stain it as an unavailable record. If Replay
owned Focus, Focus returns to the selected record.

### 10.2 Immediate and across-frame custody

When revalidation and handoff complete in the same frame, playback receives
custody directly. Gallery shows no Saving, Loading, Preparing, progress,
spinner, flash, fake delay, or transitional success.

Only a genuinely admitted handoff that remains unresolved across visible frames
uses the static double custody seam on the pinned dock. Gallery then:

- clears its internal Focus;
- preserves the exact record, witnessed version, index offset, record-paper
  offset, and originating Replay action;
- remains visibly unchanged and inert; and
- blocks shell Return and destination switching until the admitted owner
  reaches its stable boundary.

The seam is custody evidence, not an anomaly, film transport, or completion
claim.

### 10.3 Back, destination switching, and suspension

At the safe Gallery root, Back and shell Return close Gallery immediately and
restore the shell-owned Gallery ledger row. Selecting a record never creates an
extra Back layer.

During direct Endings Gallery playback, Back requests exit at the next safe
presentation boundary. No confirmation appears. Completion or safe exit
resolves the exact visited-line merge before Gallery accepts input again.

A request to switch title-ledger destination follows the same local retreat.
The new destination opens only after direct playback and any admitted merge are
cleanly resolved. Indeterminate commit and technical recovery keep the ledger
inert.

Focus loss applies quiet suspension. Presentation, Auto, TTS, public timers,
and nonessential work pause; an already-admitted bounded operation may reach
its stable frontier first. Refocus restores exact visible state without replay,
duplicate input, or repeated announcement.

These laws govern direct current-v1 Endings playback only. They do not alter the
preserved future Full Date confirmation and Rehearsal lifecycle.

### 10.4 Exact return

After a clean completion or safe exit, Gallery restores:

## 11. Absence, refusal, failure, and trusted recovery

### 11.1 Optional media absence

### 11.2 Required-record failure

A discovered record with missing required title metadata, incompatible schema,
invalid signature, or missing required English locator retains its truthful
position in personal discovery order. It never disappears, exposes an internal
ID, or replays another record.

Where its authored title remains independently trustworthy, that title remains
the index label. Otherwise the localized literal Unavailable record occupies
the record's public label. The record remains inspectable; its Replay action is
visible, Disabled, nonfocusable, and marked with the open-bottom gate. Release
UI exposes no hash, signature, path, manifest, raw code, or invented reason.

The record paper uses one exact unavailable leaf. Let T_u be the wrapped height
of an independently trustworthy title when one exists, and let U be the
wrapped Unavailable record height at a 232-pixel measure. Both are line counts
times L. Then:

- trustworthy title, when present = (196,16,252,T_u);
- unavailable-leaf y y_u = 24 + T_u when that title exists, otherwise 16;
- unavailable leaf body = (196,y_u,260,U+8);
- literal measure = (204,y_u+4,232,U);
- hatch aperture = (447,y_u+1,8,U+6); and
- leaf perimeter = one pixel, repeating two ink pixels then two bare pixels
  from its top-left.

The title's first baseline is 16 + B. The literal's first baseline is
y_u + 4 + B. The dashed perimeter and narrow hatch use contextual paper ink,
never Error colour, and never cross the literal measure. Together with the literal
they provide redundant Unavailable evidence without converting the index row
into a failure banner.

On required-record failure, optional media, authored sentence, witnessed-
version heading, witnessed-version rows, and record scroll witness have zero
geometry. The current Standard recognizes only the independently trustworthy
title as retainable public record content; it never risks attaching other
possibly misbound evidence.

This technical unavailable-record state is distinct from an ordinary
pre-admission Replay refusal, which leaves the discovered record itself
unstained.

### 11.3 Determinate start failure

If preparation fails determinately before a playback session starts:

- no session, line merge, run, profile, save, RNG, Selection, Focus, or scroll
  mutation occurs;
- the exact initiating record, version, and cached context remain;
- the dock states Replay did not begin; and
- the action becomes Retry for that exact record and version.

Retry revalidates that same semantic target. It never chooses an alternative.
Selecting another record or version clears the status and restores that newly
selected target's ordinary Replay projection. The status is factual Error
information, never character voice, horror fiction, or evidence of record
corruption. Section 7.4 owns its exact Error edge, text measure, Retry geometry,
type, clearing law, and Focus retention.

### 11.4 Indeterminate History merge

An indeterminate visited-line merge blocks archive return until the shared

Gallery never guesses, rescans visible prose, merges twice, reports success
early, or changes the candidate.

The stable Gallery remains visible and undimmed behind that shared surface, but
