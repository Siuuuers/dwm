# Recorded game audio

Revision `7ae4960` played Ogg recordings on the title and in the seven-day story.
The same music selections now resolve to looping NSF tracks. Authored effects
use timed NSFe files. The VRC6 scores and production files are listed in
[the music asset table](../../../art/pictures/README.md#music).

The original piano recordings and their credits are archived under
`art_source/audio/ishizaka/`, which the game export excludes.
