# Challenge registry reuse — 4 November 2026

## Result and ownership

Challenge admission and Finish retain the exact installed, recursively frozen
story registry instead of copying it before every authorization. GameState
recognizes that same manifest-owned object before its existing typed canonical
comparison. Mutable or equivalent-but-distinct registrations still use the
existing detached copies and comparison. Command copying and validation are
unchanged. No new cache, manager, dependency, save format or story behavior.
