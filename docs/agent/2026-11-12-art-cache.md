# Use the existing artwork cache before resource lookup

Base: `6ac3b038b8d334b3f0c19ef379dfff8eb6690088` (PR #294).

Outcome: repeated requests for one of the five cached Gallery pictures reuse the
retained texture without repeating ResourceLoader.exists. ArtManifest remains
the sole cache owner. Move that check into the existing cache-miss/path-change
branch. Path/extension and expected-size checks remain. No added cache or helper.

Before editing: fetched master, reviewed art configuration/callers, cache lifetime,
manifest reload and overlay replacement. Independent audit confirmed reload clears
the cache and set_overlay_info invalidates the affected ID. No current requirement
uses resource-file deletion during play to invalidate a retained texture. This is
not a hot-file-monitor API; ordinary non-Gallery assets still use the existence path.

Matched headless measurements (Godot 4.6.3), A/B/B/A fresh-process order:

| Version | 5,000 cached lookups | 100 complete art refreshes |
| --- | --- | --- |
| Base A | 15.315 ms | 2.025 ms |
| Candidate A | 11.532 ms | 3.059 ms |
| Candidate B | 11.313 ms | 1.756 ms |
| Base B | 15.070 ms | 1.931 ms |

The isolated lookup saves about 0.75 microseconds per call. Complete refresh costs
are noisy and establish no improvement; no visible/player-operation speedup is
claimed. The full refresh uses authored draft.reading.early and includes texture
lookup, view configuration and signal emission; deferred rendering is excluded.
An earlier diagnostic used a non-Gallery scene and is excluded from this comparison.

Final candidate checks: benchmark identity/size assertions (2 x 16), new focused
cache ownership test (13), existing seven-day authored asset/split placement test
(96): 141 passing assertions. Commands exit 0, XML cases pass, no ERROR lines.
`git diff --check` passed. Unit check covers matching/wrong expected size, reuse,
overlay replacement and manifest reload without introducing file-deletion tests.
No behavior retired; no new lint rule.

Evidence includes logs, XML and runners. Copy probes to `.godot/ci/art-cache`.
`run.py <fresh-label> unused test_refresh_cost` runs the benchmark;
`focused.py <fresh-label> unit/test_art_texture_cache
 test_cached_picture_retains_size_checks_and_replacement_ownership` checks cache
ownership. The authored filter is `integration/test_artwork_gallery` /
`test_seven_day_art_assets_and_split_placement`.

Skipped broad suites, new Save/Load timing, rendered/Windows checks and injection
campaigns. The change does not alter save or input code. Future optimization should
return to a reproducible player pause rather than chasing sub-microsecond savings.
