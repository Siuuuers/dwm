# Schedule desktop evidence

The final isolated GUT runs and native matrix are recorded in summary.json.
Source SHA-256 and Git blobs bind the seven authored runtime/test files.
All attempts remain in invocations.jsonl with normalized logs and raw log hashes.

The initial focused run exposed hidden-warning deferred focus stealing. Visual
inspection rejected the first native fixture because its newly authored Chinese
names had been corrupted by the shell encoding despite passing geometry checks.
The fixture text and deferred focus were corrected before final acceptance.
Final native coverage is 18 language/text-size/target-size combinations. Captures
use ordinary action fixture names, real injected draft/presentation/desktop owners,
and isolated identity/storage. They do not demonstrate production persistence,
canonical Done execution, Day7 gameplay or platform screen-reader acceptance.

Existing Unicode NUL diagnostics and Dialogic fixture orphans remain in the logs;
passing is not a leak-free claim. See ../../docs/design/current-ui/schedule-desktop-integration.md.
