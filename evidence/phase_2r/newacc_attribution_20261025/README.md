## Interpretation

New Acc configures the reading catalogue 90 times fresh and 96 times retained.
It invokes the compiler 8,300/8,853 times respectively. Compiler calls can hit
the existing cache; these numbers do not mean that many physical parses.

Configuration takes 3.818–4.474 s. Compilation takes 2.110–2.332 s **inside**
configuration and other callers. These categories and the owner phases are
inclusive; do not add nested observations together.

Settlement takes 3.690–4.017 s and includes 28 configurations plus 2,581 compiler
calls. It is not a pure disk-I/O duration. The snapshot-detail arrays are empty
in all four reports. This is a coverage limit, not evidence of free validation.

This runner's shorter overall durations do not establish a speedup over earlier
runs. No product behavior was optimized. See the
[handoff](../../../handoff/z-newacc-attribution-20261025.md) for the stage map,
bounded next candidate and required failure checks.
