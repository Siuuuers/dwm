It previously called `make_scene_receipt`, which validated the same bundle a second time before any issuer callback. This candidate reuses only that first call's detached registration result inside the same synchronous constructor invocation. Successful construction saves one complete bundle validation. It does not establish an elapsed-time improvement or attribute all measured bundle cost to terminal construction.

Ordinary public receipt/context entrypoints still inspect fresh version/shape before freshly validating their bundle. Terminal keeps issuer binding, fresh bundle, target and trigger checks ahead of nested event checks; only its redundant second bundle computation disappears. Shape inspection independently deep-copies semantic data. Binding mutates the new shape result, not the registration tables. There is no await or issuer callback in this interval. All later `verify_issued`, `validate_child`, `derive_child`, terminal shape checks, full ledger/reconstruction validation, public fresh bundle checks and recovery boundaries remain byte-identical. No cache, optional trusted public argument, saved field or callback contract was added.

It reverses all three extractions and the one terminal call replacement and asserts recovery of the baseline bytes. It also compares complete bodies of all 50 unchanged existing functions and separately verifies that the terminal body differs only at that call site. `transformation-proof.json`, `manifest.json` and `candidate.patch` record the result. Run the script with Python and the exact baseline path; it does not execute game code.
