  --archive original-evidence.zip \
  --archive-sha256 60479645cd8314b9413fb4e4cf3e84394f208c4b2f917b4c83e74948978d1c82 \

  --original verify-output/original/ci \

copies that verified evidence and runs the reviewed corrected binder with the
unchanged reader from `analysis/sources/`. It refuses an existing output
directory or one nested inside the original evidence. Its receipt checks the
original file census and analysis source bytes before and after. Recreated
derived reports are under `reanalysis-output/evidence-copy/ci/`; the published
counterparts are under `analysis/`.

A verifier exit `0` means custody passed. A reanalysis exit `0` means this
qualified prepared-graph binding passed. Neither changes the failed cloud Load,
the original cloud binder report or the original acceptance result. These
commands launch no Godot, PowerShell or native gameplay process.
