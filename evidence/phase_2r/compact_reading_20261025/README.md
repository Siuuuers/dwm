# Compact reading and current-day History — 25 October 2026

## Observable outcome

Load restores the complete current caption or authored held-control predecessor without
replaying prior effects. Current-day History and caption scrolling reconstruct one passage
from authored DTL, current position, choices and Challenge outcomes. The next day clears
the displayed passage. Global read and Gallery facts remain independent. Contacts are
excluded from the new display reconstruction.

## Boundaries

Player reading schema 6 contains a stable current line/control locator, compatibility marker,
current occurrence and one genuine caption/publication reference. It omits the reading ledger,
entry-context history and traversal operation. The publication serial prevents ID reuse.
Full live capture still owns traversal and reversible rollback. Native activation/input fences
remain; post-durable activation failure is still input-blocked.

Genuine top-level story receipts remain for active story/Challenge/Contacts consumers.
Current progress is still checked against those receipts. Historical caption membership is
no longer a Load prerequisite. Ending-source reading is projected, not yet removed; audio
context and application metadata remain. This is a coherent reading increment, not completion
of every compact-save removal. No performance improvement is claimed.
