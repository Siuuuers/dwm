## Outcome and owner

`GalleryRecordCatalog` now resolves optional, authored `version_cue` copy only
for the matching exact signature and semantic record. Its existing catalogue
validation owns admission. A cue requires three nonblank localized strings;
lookup retains the catalogue's existing locale-alias mapping. Missing cues return
empty rather than deriving copy from a sentence, signature field or version index.
Ending-level defaults cannot supply exact-version cues. Inputs remain detached.

The existing `projection()` result still contains only sentence and media.
Production `PRESENTATION_DETAILS` remains empty. No production labels, UI,
selection, Replay admission, chronology, save, recovery or History owner changed.
In particular, missing cues do not make existing plural records unavailable.
