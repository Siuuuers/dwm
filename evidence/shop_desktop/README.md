# Shop desktop evidence

The final isolated GUT runs pass 114 tests / 2896 assertions in ten suites.
The native shared-host matrix passes 386 checks across 18 language/text-size/target
combinations. Four additional captures verify both Standard palette fixtures.
Source SHA-256 and Git blobs bind all fifteen adapted/authored source and test files.
All attempts are retained with invocation receipts and normalized logs/raw hashes.

Initial failures exposed a deferred startup focus race, source-versus-copy quantity
classification, and a pointer fixture delivering events into the runner viewport.
Fixes retain same-frame opening and real pointer/keyboard/controller event coverage.
The first native attempt rejected an untyped local expression before rendering.
The first palette run exited 0 but emitted teardown errors; it is rejected. Named
viewport observation, detached-view guards and pending-layout resumption address
teardown and same-data remount regressions. Final logs are checked for script errors.

Transparent textures and ShopCopy names are synthetic presentation fixtures, not
production artwork, owner copy, provenance or entitlement. No purchase is executed.
These checks do not claim production persistence or platform screen-reader acceptance.
Existing Unicode NUL diagnostics and 24 Dialogic fixture orphans per GUT run remain
in the logs; passing is not a leak-free claim.
