# Schedule refused-edit status checkpoint

Following 9b993602a, an admitted edit refused for a stale view, disappeared or
unavailable source, invalid target, missing occurrence, or Day-7 move now publishes
the accepted localized `Unavailable` fact in the pinned dock. Technical failures
continue to request recovery. The status uses the exact ordinary/Large geometry,
Fog Blue leading rule and Bone text on the controlled-dark habitat. Idle creates
no status node. It neither changes the draft nor becomes a focus stop.

The App assigns one local identity per admitted command. Duplicate refusal
delivery, projection, locale reflow and focus restoration retain the same fact
without another announcement request. Successful edits, admitted Done, safe
departure, cache invalidation and recovery clear it. New results replace it.
One retained identity replaces an unnecessary unbounded announcement dictionary;
the synchronous delivery contract needs no historical receipt ledger.

A newly admitted refusal configures the Label as LIVE_POLITE; reconstruction and
duplicate-after-clear use LIVE_OFF. The signal is a deterministic test seam.
These checks prove API state, not actual Windows screen-reader delivery or its
timing; native assistive technology verification remains open. See the
[Godot Control accessibility API](https://github.com/godotengine/godot/blob/4.6-stable/doc/classes/Control.xml).
