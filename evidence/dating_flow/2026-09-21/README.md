- Solo Observer eligibility no longer requires those interaction receipts. Four exact canonical Perfect boards, the eligible selected Day 7 Sweet destination, actual ending completion, and full/residue behavior remain. Pair Observer gates retain their independent requirements.
- Dating plays the matching semantic pre/post DTL entries and advances on natural completion. Ordinary clears settle as Loved automatically; Perfect and explosion consequences retain their existing rules. The special-mine action and routine start/end confirmation cards are unavailable.
- Empty entries return automatically without manufactured witnessed prose. Real failures retain Retry. Tests cover terminal paint before settlement, held-input separation, exactly-once effects, old terminal-choice saves, same-phase Load, and ordinary checkpoint Retry.
- The real Bridge tests exercise an empty entry with available artwork and an entry containing two actual lines. The private Gallery test now waits for automatic board admission instead of pressing a removed confirmation.

Current rules and ownership are documented in [Observer suspension](../../../docs/design/current-ui/observer-interactions-suspended-2026-09-21.md) and [automatic dating flow](../../../docs/design/current-ui/automatic-dating-flow-2026-09-21.md).
